## 🐛 Reporting a problem
Use the repository Bug Report issue form. Include affected question/file, browser, viewport, steps to reproduce, and sanitized evidence.

Do not include credentials or private personal information. Use synthetic examples when reproducing markup problems.

## 💡 Suggesting improvements
Use the Feature Request issue form and explain the learning benefit and acceptance criteria. Source changes to original coursework should be separately scoped.
