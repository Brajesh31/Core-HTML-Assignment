# 🔐 Security Policy

## 📌 Scope
This repository contains static HTML assignment examples and documentation. No backend service, account system, or server-side data store is established by current repository.

## 🚨 Reporting a vulnerability
Use GitHub's private **Report a vulnerability** feature if enabled. Do not publish exploit details or sensitive information in a public issue.

Include:
- Affected file and commit.
- Clear impact description.
- Reproduction steps using non-sensitive sample data.
- Sanitized evidence and proposed mitigation.

## 🛡️ Repository practices
- Never commit credentials, tokens, private keys, or local environment secrets.
- Keep GitHub Actions permissions to the minimum required.
- Avoid executing untrusted scripts from issues or pull requests.
- Treat external hyperlinks as destinations outside repository control.
- Do not claim static HTML pages provide authentication or protected storage.
