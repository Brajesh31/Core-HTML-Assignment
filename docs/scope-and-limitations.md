# 🎯 Scope and Limitations

## ✅ In scope

- Eight original question HTML documents.
- Three-page Question 3 mini-site and its relative navigation.
- Existing screenshot evidence for each exercise.
- Documentation, architecture diagrams, governance templates, and repository validation tools.

## 🚫 Out of scope for this pass

- Rewriting assignment HTML content.
- Converting examples into a React/Vue/Angular application.
- Introducing JavaScript frameworks, Node.js, npm, a backend, or a database.
- Replacing original screenshot evidence.
- Claiming responsive, accessibility, or browser tests were passed without running them.
- Adding remote links as application features.

## ⚠️ Limitations of the current submission

The files are simple educational examples. Some markup is worth reviewing for semantic correctness and HTML conformance. The Question 3 pages use inline styles and static content. No dedicated CSS design system, responsive layout framework, automated test runner, or browser interaction logic is established.
