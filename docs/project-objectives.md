# 🎯 Project Objectives

## 📌 Learning objectives reflected by the assignment

| Objective | Assignment evidence |
|---|---|
| Format inline text semantically. | Q1 uses strong/emphasis/underline/mark/sup/sub/small/del examples. |

## 🧠 Skills demonstrated

- HTML document structure and metadata.
- Text semantics and inline elements.
- Anchor navigation and relative paths.
- Header and navigation region concepts.
- Ordered, unordered, and description lists.
- Table captions, row/column headers, and cell spans.
- Basic embedded CSS for visual formatting.
