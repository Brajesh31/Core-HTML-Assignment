# 🧱 Project Overview

## 📌 What this repository is

Core HTML Assignment is a collection of foundational HTML tasks. It contains eight question documents under `Assignment_2_Core html/`, plus the three related Question 3 pages.

The tasks cover text formatting, hyperlinks, simple multi-page navigation, HTML tag examples, description lists, tables, nested lists, and a conference schedule table.

## 🎯 Intended use

The repository works as:
- A learning record for foundational HTML elements and document structure.
- A set of independent examples that can be opened in a browser.
- A small reference for semantic text, hyperlinks, lists, and tabular data.
- A portfolio of assignment pages paired with existing screenshots.
