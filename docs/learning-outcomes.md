# 🧠 Learning Outcomes

| Concept | Assignment | What to learn |
|---|---|---|
| Text semantics | Q1 | Distinguish importance, emphasis, annotation, insertion/deletion, and sub/superscript. |
| Hyperlinks | Q2 | Use anchors with descriptive link text and meaningful destinations. |
| Site navigation | Q3 | Link local pages with relative paths and structure header/nav content. |
| HTML element vocabulary | Q4 | Recognize common tags and intended semantics. |
| Description list | Q5 | Pair terms with descriptions using `dl`, `dt`, and `dd`. |
| Data tables | Q6 | Use captions, header cells, and data cells for tabular relationships. |
| Nested lists | Q7 | Represent hierarchy using nested list elements. |
| Spanning table cells | Q8 | Understand how `rowspan` and `colspan` change table geometry. |

## 🔁 Suggested study sequence

1. Start with Q1 and Q2 to understand inline semantics and navigation.
2. Work through Q3 and Q4 to connect page structure to element vocabulary.
3. Study Q5 and Q7 for different list semantics and content hierarchy.
4. Compare Q6 and Q8 to understand table structure and spanning.
5. Revisit each file using the glossary and accessibility checklist.
