# 📖 HTML Concepts Glossary

| Concept | Meaning |
|---|---|
| HTML | Markup language used to describe structure and semantics of web content. |
| Element | A document construct usually formed by a start tag, content, and end tag. |
| Attribute | Additional information supplied in an element's start tag. |
| Semantic element | Element whose name communicates meaning or role. |
| `strong` | Indicates strong importance, seriousness, or urgency. |
| `em` | Indicates stress emphasis. |
| `i` | Represents text in an alternate voice/mood or otherwise offset from prose. |
| `u` | Represents non-textual annotation; not a generic replacement for emphasis. |
| `mark` | Highlights text for reference or relevance. |
| `sup` / `sub` | Superscript/subscript text. |
| `del` | Represents text deleted from a document. |
| Anchor (`a`) | Creates a hyperlink when an `href` is provided. |
| Relative URL | Link resolved relative to the current document location. |
| `header` | Introductory content for a page or section. |
| `nav` | Section containing navigation links. |
| `ol` | Ordered list. |
| `ul` | Unordered list. |
| `li` | List item. |
| `dl` | Description list. |
| `dt` | Term/name in a description list. |
| `dd` | Description/details associated with a term. |
| `table` | Tabular data structure. |
| `caption` | Title/description for a table. |
| `th` | Header cell. |
| `td` | Data cell. |
| `rowspan` | Number of table rows a cell spans. |
| `colspan` | Number of table columns a cell spans. |
| Viewport metadata | Meta declaration controlling layout viewport on mobile browsers. |
| Embedded CSS | CSS inside a document's `style` element. |
| Inline CSS | CSS supplied by an element's `style` attribute. |
