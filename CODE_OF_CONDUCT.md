# 🤝 Code of Conduct

## Our commitment
We aim to keep this learning repository welcoming, respectful, and useful for people with different backgrounds and levels of experience.

## Expected behavior
- Be respectful and constructive.
- Explain technical feedback with evidence and context.
- Welcome beginner questions and corrections.
- Focus on the code or idea, not the person.
- Respect the original coursework and its authorship context.

## Unacceptable behavior
- Harassment, insults, discrimination, or threats.
- Publishing another person's private information.
- Deliberate disruption or abusive comments.
- Misrepresenting another contributor's work.

## Reporting
Contact the repository maintainer through GitHub's available private contact/reporting channels. Do not include sensitive details in public issues.
